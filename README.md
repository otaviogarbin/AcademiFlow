# 🎓 **AcademiFlow — Sistema de Gerenciamento de Atividades Acadêmicas**

## 🌐 Visão Geral

O **AcademiFlow** é uma plataforma web projetada para simplificar o gerenciamento e o acompanhamento de atividades acadêmicas em instituições de ensino.
O sistema permite que **professores** criem e administrem atividades, enquanto **alunos** podem visualizá-las e confirmar sua participação.

📍 **Instituição:** Escola Laguna
🧩 **Versão:** 1.0
👥 **Equipe:** Otávio Garbin, Felipe Santos, Felipe Chagas, Giovanna Alves

## ❗ Problema Identificado

### 🔍 Necessidade Real

As instituições de ensino frequentemente enfrentam problemas como:

* 📢 Comunicação desorganizada entre professores e alunos
* 🔎 Dificuldade em rastrear participação
* 🗓️ Informações dispersas sobre datas, horários e detalhes
* ❌ Falta de um sistema para confirmação de presença

### 👥 Público Beneficiado

* 👨‍🏫 **Professores:** criar, organizar e monitorar atividades
* 🎓 **Alunos:** visualizar e confirmar participação
* 🏫 **Gestão Escolar:** obter controle centralizado e organizado

### 🌟 Impacto do Sistema

* 📚 Centralização das informações
* 🗣️ Comunicação mais clara
* 🚀 Aumento no engajamento dos alunos
* ⚙️ Facilitação geral da gestão acadêmica
