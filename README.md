# AcademiFlow - Sistema de Gerenciamento de Atividades Acadêmicas

## Visão Geral

O **AcademiFlow** é uma plataforma web desenvolvida para facilitar o gerenciamento e acompanhamento de atividades acadêmicas em instituições de ensino. O sistema permite que professores criem e gerenciem atividades, enquanto alunos podem visualizá-las e confirmar sua participação.

**Instituição:** Escola Laguna  
**Versão:** 1.0  
**Equipe:** Otávio Garbin, Felipe Santos, Felipe Chagas, Giovanna Alves

## Problema Identificado

### Necessidade Real
Escolas enfrentam dificuldades em gerenciar atividades acadêmicas de forma centralizada, levando a:
- Comunicação desorganizada entre professores e alunos
- Falta de rastreamento de participação
- Perda de informações sobre datas, horários e detalhes de atividades
- Impossibilidade de confirmar presença ou participação

### Público Beneficiado
- **Professores:** Organizar atividades e acompanhar participação
- **Alunos:** Visualizar atividades disponíveis e confirmar participação
- **Gestão Escolar:** Melhor controle administrativo

### Impacto
- Centralização de informações
- Comunicação mais clara e organizada
- Maior engajamento dos alunos
- Facilita gestão acadêmica
